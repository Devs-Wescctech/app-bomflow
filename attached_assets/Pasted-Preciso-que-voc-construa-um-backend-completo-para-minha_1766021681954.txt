Preciso que você construa um backend completo para minha aplicação React importada do Base44. Siga estes processos:

1. ANÁLISE DO FRONTEND:
Antes de criar qualquer coisa, analise o código em src/api/ e src/pages/ para identificar:

Quais entidades existem no sistema
Quais endpoints estão sendo chamados
Quais campos cada entidade possui
Quais operações são feitas (CRUD, filtros, etc)
2. ESTRUTURA DO BACKEND:
Criar pasta backend/ com estrutura organizada: src/config/ para configurações e schemas SQL, src/middleware/ para autenticação, src/routes/ para cada entidade, src/utils/ para funções auxiliares, src/server.js como entry point.

3. BANCO DE DADOS:

Criar schema SQL com todas as tabelas baseadas nas entidades do frontend
Usar UUIDs como chave primária
Criar índices para campos de busca frequente
Usar triggers para atualizar timestamps automaticamente
Executar schema automaticamente ao iniciar servidor
4. AUTENTICAÇÃO:

Implementar JWT com access token e refresh token
Criar middlewares de proteção de rotas
Rotas de registro, login, logout, refresh token e dados do usuário
Hash de senhas com bcrypt
5. ROTAS DA API:

Criar rotas CRUD para cada entidade
Rotas protegidas usam middleware de autenticação
Rotas públicas (como busca por slug) não precisam de auth
Validar dados de entrada
Retornar erros apropriados
6. UPLOAD DE ARQUIVOS:

Configurar Multer para upload local
Servir pasta de uploads como arquivos estáticos
Criar rota dedicada para upload
7. CONFIGURAÇÃO DO SERVIDOR:

Usar CORS para aceitar requisições do frontend
Configurar limite de tamanho para JSON
Escutar em 0.0.0.0 para funcionar no Replit
Criar rota /api/health para verificação
8. CONEXÃO FRONTEND-BACKEND:

Ajustar cliente API do frontend para chamar /api/
Manter estrutura de chamadas existente
Adicionar headers de autenticação nas requisições
9. DOCKERFILE:

Usar node:20-slim para compatibilidade
Instalar dependências de sistema necessárias
Configurar permissões para pasta de uploads
Criar healthcheck
Rodar como usuário não-root
10. VARIÁVEIS DE AMBIENTE:

DATABASE_URL para conexão PostgreSQL
JWT_SECRET para tokens
Outras configurações sensíveis
11. WORKFLOWS:

Configurar workflow separado para backend
Frontend deve rodar na porta 5000 para webview do Replit
DEPENDÊNCIAS NECESSÁRIAS:
express, pg, cors, multer, dotenv, bcryptjs, jsonwebtoken
