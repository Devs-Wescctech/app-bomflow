Abaixo estão as informações completas e exclusivas sobre a API de busca de indicador (getCustomerFromERP), conforme solicitado:

Documentação da API: getCustomerFromERP
Esta função integra com o ERP Bom Pastor para validar se um CPF pertence a um cliente ativo e retorna os dados cadastrais e de contrato.

Endpoint da Função: getCustomerFromERP Método de Chamada: POST (via SDK base44.functions.invoke)

1. Payload de Envio (Request)
O que você deve enviar para a API:

{
  "cpf": "11898902755"  // CPF do indicador (com ou sem pontuação)
}

3. Possíveis Erros (Status não-200)
Cliente não encontrado ou sem contrato ativo:

Status HTTP: 404
Body:
{
  "success": false,
  "error": "Nenhum dado encontrado para este CPF",
  "notFound": true,
  "noContract": true
}
Erro de Validação:

Status HTTP: 400
Body: {"success": false, "error": "CPF inválido"}
Integração Interna (Backend -> ERP)
A função realiza a seguinte chamada para o ERP legado:

URL: http://erp.wescctech.com.br:8080/BOMPASTOR/api/API_CRM?cpf={cpf_limpo}
Headers:
Authorization: {033CC53E52AB68451304CB751BC9D476D25789AC}
Cookie: JSESSIONID={ERP_JSESSIONID}; BOMPASTOR.SID={ERP_JSESSIONID}
