Para migrar essa aplicação do Base44 para um ambiente próprio (Replit/Servidor Node.js), você precisará reconstruir a infraestrutura que o Base44 fornece automaticamente (Banco de Dados + API CRUD + Autenticação).

Aqui está o Documento Técnico de Migração com tudo o que você precisa:

1. Banco de Dados (Database)
Você precisará de um banco de dados (recomendo PostgreSQL ou MongoDB). Aqui estão as tabelas (entidades) e suas colunas principais baseadas no esquema atual:

Tabelas Principais (Core)
Users (Você precisará criar essa tabela para autenticação, já que o Base44 gerenciava isso): id, email, password_hash, full_name, role, created_at.
Agent: id, name, cpf, user_email, agent_type (support, sales, etc.), team_id, skills (array), active.
Team: id, name, supervisor_email.
Queue (Filas): id, name, team_id, default_priority.
Módulo de Qualidade (Sua feature atual)
CallAudit:
id, audio_url, agent_id, score (0-100), summary (text), transcription (text), duration (int), processed_at, status.
analysis (JSON - guarda sentimentos, pontos fortes/fracos).
dialogue (JSON/Array - guarda a transcrição separada por speaker).
QualityChecklist:
id, name, description, items (JSON - guarda o array de objetos {text, weight}), is_default.
Módulo de Vendas (CRM)
LeadPJ: id, cnpj, company_name, stage (pipeline), agent_id, value, contact_info (JSON).
ActivityPJ: id, lead_id, type (call, email), description, date.
LeadPJAutomation: id, name, trigger_type, action_config (JSON).
Módulo de Atendimento
Ticket: id, subject, status, priority, customer_id, assigned_agent_id.
TicketMessage: id, ticket_id, body, sender_type (agent/customer).

4. Lógica de Backend (O que você precisa codar)
O Base44 fornece APIs prontas (base44.entities.X.list()). No seu servidor, você terá que criar rotas manuais para isso.

A. Rotas CRUD (Exemplo Express)
Você terá que criar endpoints para cada entidade. Exemplo para QualityChecklist:

GET /api/quality-checklists (Listar)
POST /api/quality-checklists (Criar)
PUT /api/quality-checklists/:id (Atualizar)
DELETE /api/quality-checklists/:id (Deletar)
B. Migração da Função processCallAudit
A lógica que está hoje em functions/processCallAudit.js (Deno) precisa ser portada para uma rota Node.js/Express.

Fluxo da Rota POST /api/audit/process:

Receber audio_url, agent_id, checklist_id.
Buscar o Checklist no banco de dados para pegar os itens e pesos.
Baixar o arquivo de áudio (usando fetch ou axios).
Enviar para OpenAI Whisper (openai.audio.transcriptions.create) para transcrever.
Montar o prompt com a transcrição + itens do checklist.
Enviar para GPT-4o (openai.chat.completions.create) pedindo o JSON de resposta.
Calcular o Score baseado no retorno.
Salvar o resultado na tabela CallAudit.
Retornar o resultado para o frontend.

Rotas da API (Endpoints)
Você terá que criar rotas CRUD para TODAS as tabelas acima. Exemplo padrão: GET /api/agents, POST /api/agents, PUT /api/agents/:id.

Rota Especial: Processamento de Auditoria (A "Mágica") Esta é a rota que substitui a processCallAudit do Base44. Ela deve estar em POST /api/audits/process.

// controllers/auditController.js
const OpenAI = require('openai');
const db = require('../config/db'); // Seu cliente Postgres
const axios = require('axios');
const fs = require('fs');

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

exports.processAudit = async (req, res) => {
    try {
        const { audio_url, agent_id, checklist_id } = req.body;

        // 1. Buscar Checklist do Banco
        const checklistRes = await db.query('SELECT items FROM quality_checklists WHERE id = $1', [checklist_id]);
        const checklistItems = checklistRes.rows[0]?.items || [];

        // 2. Download do Áudio
        const audioResponse = await axios.get(audio_url, { responseType: 'arraybuffer' });
        const audioBuffer = Buffer.from(audioResponse.data);
        // Salvar temp para o Whisper (biblioteca openai exige arquivo ou stream fs)
        const tempFilePath = `/tmp/audio-${Date.now()}.mp3`;
        fs.writeFileSync(tempFilePath, audioBuffer);

        // 3. Transcrever (Whisper)
        const transcription = await openai.audio.transcriptions.create({
            file: fs.createReadStream(tempFilePath),
            model: "whisper-1",
            language: "pt",
            response_format: "verbose_json"
        });

        // 4. Análise Inteligente (GPT-4o)
        // Montar o System Prompt igual ao que criei anteriormente
        const systemPrompt = `Você é um auditor... (copiar o prompt do arquivo functions/processCallAudit.js) ...
        Checklist: ${JSON.stringify(checklistItems)}`;

        const gptResponse = await openai.chat.completions.create({
            model: "gpt-4o",
            messages: [
                { role: "system", content: systemPrompt },
                { role: "user", content: transcription.text }
            ],
            response_format: { type: "json_object" }
        });

        const analysisData = JSON.parse(gptResponse.choices[0].message.content);

        // 5. Salvar no Banco
        const insertQuery = `
            INSERT INTO call_audits 
            (agent_id, audio_url, duration, transcription, dialogue, analysis, score, status, processed_at)
            VALUES ($1, $2, $3, $4, $5, $6, $7, 'completed', NOW())
            RETURNING *
        `;
        
        const newAudit = await db.query(insertQuery, [
            agent_id, 
            audio_url, 
            transcription.duration, 
            transcription.text,
            JSON.stringify(analysisData.dialogue), 
            JSON.stringify(analysisData), 
            analysisData.score
        ]);

        // Limpar temp
        fs.unlinkSync(tempFilePath);

        res.json({ success: true, data: newAudit.rows[0] });

    } catch (error) {
        console.error(error);
        res.status(500).json({ error: error.message });
    }
};

Onde tem:

import { base44 } from "@/api/base44Client";

import api from "@/services/api"; // Instância do Axios configurada

Serviço de API (src/services/api.js):

import axios from 'axios';

const api = axios.create({
  baseURL: process.env.REACT_APP_API_URL || 'http://localhost:3000/api',
});

// Interceptor para injetar Token JWT
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default api;
