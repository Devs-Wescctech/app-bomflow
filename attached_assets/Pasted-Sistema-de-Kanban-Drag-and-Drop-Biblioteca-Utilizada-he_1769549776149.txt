Sistema de Kanban Drag-and-Drop
Biblioteca Utilizada
@hello-pangea/dnd (fork mantido do react-beautiful-dnd)
Arquivos Afetados
src/pages/LeadsKanban.jsx (Leads PF)
src/pages/LeadsPJKanban.jsx (Leads PJ)
src/pages/ReferralPipeline.jsx (Indicações)
Estrutura HTML/CSS
Container (overflow-x-auto, cursor-grab)
└── DragDropContext
    └── div (flex gap-4, minWidth: max-content)
        └── Card (w-72, altura fixa calc(100vh - 280px))
            └── Header (gradiente colorido)
            └── CardContent (flex-1 p-0, SEM overflow)
                └── Droppable
                    └── div (p-3, min-h-full)
                        └── Draggable (cada card)
Refs Utilizadas (não useState!)
kanbanContainerRef - referência ao container do kanban
isDraggingCanvasRef - true quando arrastando o canvas
isDraggingCardRef - true quando arrastando um card
dragStartX, dragScrollLeft - posições iniciais do drag
autoScrollIntervalRef - intervalo do auto-scroll
Funções Principais
handleCanvasMouseDown/Move/Up/Leave - arrastar canvas no espaço vazio
handleDragStart - inicia auto-scroll horizontal
cleanupDrag - limpa intervalos e event listeners
onDragEnd - processa a mudança de coluna/ordem
Auto-Scroll Horizontal
setInterval a cada 16ms verifica posição do mouse
Se mouse < 80px da borda esquerda → scrollLeft -= 8
Se mouse > 80px da borda direita → scrollLeft += 8
Posição do mouse rastreada via window.lastMouseX
Regras Críticas (NÃO ALTERAR!)
NÃO usar overflow-y-auto nas colunas - causa erro de "nested scroll container"
NÃO usar useState para flags de drag - causa re-renders que quebram o arrasto
Usar refs para todas as variáveis de drag
cleanupDrag ANTES de onDragEnd no DragDropContext
Bloquear canvas drag quando isDraggingCardRef.current é true
Configuração do DragDropContext
<DragDropContext 
  onDragStart={handleDragStart} 
  onDragEnd={(result) => { cleanupDrag(); onDragEnd(result); }}
> 
Funcionalidades
Arrastar cards de uma coluna para outra
Auto-scroll horizontal ao arrastar para as bordas
Arrastar o canvas clicando no espaço vazio
Reordenação de cards na mesma coluna
